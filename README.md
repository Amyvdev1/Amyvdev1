### How I approach the work

```text
Listen to the real need  →  Make the workflow visible  →  Build the smallest reliable system  →  Test and document the handoff
```

- **Product surfaces:** Responsive interfaces that turn complex work into an understandable next move.
- **Workflow logic:** Explicit ownership, states, approval points, and handoffs rather than hidden assumptions.
- **API foundations:** Structured validation and predictable contracts that give frontend work a reliable boundary.
- **AI with guardrails:** Optional AI assistance that preserves transparency, sensible fallbacks, and human judgment.
- **Accessible delivery:** Keyboard-operable controls, semantic structure, clear feedback, and regression testing practice.
- **Bilingual communication:** Native English and Spanish in technical, operational, and customer-facing settings.
