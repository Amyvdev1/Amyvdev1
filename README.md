## How I approach the work

```text
Understand the real need → make the workflow visible → build the smallest reviewable system → test and document the handoff
```

- **Product surfaces:** Responsive interfaces that turn complex work into an understandable next move.
- **Workflow logic:** Explicit ownership, states, approval points, and handoffs instead of hidden assumptions.
- **API foundations:** Structured validation and predictable contracts that provide a dependable boundary for frontend work.
- **AI with guardrails:** Optional AI assistance with visible execution state, sensible fallback behavior, and human judgment.
- **Accessible delivery:** Keyboard-operable controls, semantic structure, clear feedback, and focused regression testing practice.
- **Bilingual communication:** Native English and Spanish in technical, operational, and customer-facing settings.
